# 💻 Tailwind Landing Page Project

Proyek landing page sederhana yang dibangun menggunakan Tailwind CSS. Repo ini berisi halaman HTML statis untuk menampilkan informasi produk/layanan secara ringkas dan menarik.

<img width="1894" height="868" alt="image" src="https://github.com/user-attachments/assets/36ccd2d1-f3da-48ab-b0f1-99f5aa850f57" />

---

## Ringkasan
- Teknologi utama: Tailwind CSS + HTML (komposisi bahasa: 100% HTML).
- Tujuan: Menyediakan template landing page yang mudah dikustomisasi.
- Sifat proyek: Statis (tanpa backend). 


## Fitur
- Desain responsif siap pakai (mobile-first).
- Komponen umum landing page: hero, fitur, CTA, footer, dsb.
- Mudah disesuaikan warna, tipografi, dan layout dengan kelas Tailwind.

---

## Cara Menggunakan
1. Clone repo:
   ```
   git clone https://github.com/bagaspng/Tailwind-Landing-Page-Project.git
   ```
2. Buka file `index.html` langsung di browser, atau gunakan ekstensi Live Server (VS Code) untuk pengalaman pengembangan yang lebih nyaman.
3. Ubah konten teks, gambar, dan kelas Tailwind sesuai kebutuhan Anda.

Jika menggunakan Tailwind via CDN (disarankan untuk proyek kecil/cepat mulai), pastikan ada skrip berikut di `<head>`:
```html
<script src="https://cdn.tailwindcss.com"></script>
```
